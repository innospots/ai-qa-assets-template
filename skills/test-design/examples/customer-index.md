# 客户管理测试设计

## 1. 模块说明

客户管理模块用于维护平台中的客户基础资料，包括创建、修改、查询、启停和删除。

本模块测试重点：

- 客户信息正确性与唯一性
- 角色权限与租户隔离
- 客户状态变化
- 页面、接口与持久化一致

## 2. 测试目标

验证：

1. 客户基础信息能够正确维护
2. 客户编号在同一平台内不重复
3. 不同角色按权限访问客户
4. 不同租户之间数据隔离
5. 客户状态变化符合状态模型
6. 操作结果在查询、详情与持久化中一致

## 3. 模块范围

包含：

- 创建客户
- 修改客户
- 查询客户
- 启用客户
- 停用客户
- 删除客户

暂不包含：

- 客户批量导入
- 客户数据迁移

## 4. 用户与角色

| 角色 | 查询 | 创建 | 修改 | 删除 | 启停 |
| --- | --- | --- | --- | --- | --- |
| 系统管理员 | ✓ | ✓ | ✓ | ✓ | ✓ |
| 运营人员 | ✓ | ✓ | ✓ | - | ✓ |
| 查看人员 | ✓ | - | - | - | - |

场景若有额外权限约束，在对应场景 TDS 中补充。

## 5. 公共前置条件

- 用户已登录
- 当前租户状态正常
- 客户管理服务可用
- 用户所属组织有效

## 6. 公共业务规则

### 客户编号

- 必填
- 最大 32 个字符
- 同一平台内唯一
- 创建后不允许修改

### 客户名称

- 必填
- 长度 1～100 个字符
- 保存时去除前后空格

### 租户隔离

客户必须属于当前租户。任何用户不得查询或修改其他租户的客户。

## 7. 数据与状态模型

```text
正常
 ↓
停用
 ↓
恢复为正常
```

| 当前状态 | 操作 | 目标状态 | 是否允许 |
| --- | --- | --- | --- |
| 正常 | 停用 | 停用 | 是 |
| 停用 | 启用 | 正常 | 是 |
| 正常 | 启用 | — | 否 |
| 停用 | 停用 | — | 否 |
| 已删除 | 启停 / 修改 | — | 否 |

## 8. 公共测试数据

只声明名称与用途，具体值放 `data/customer/`（示例模块可不落真实 data 文件）。

| 名称 | 用途 |
| --- | --- |
| `users.admin` | 系统管理员 |
| `users.operator` | 有创建/修改/启停权限的运营人员 |
| `users.viewer` | 仅查询 |

| `customers.disabled` | 已停用客户 |

## 9. 公共测试要求

业务操作除界面可见结果外，按场景验证：

- 接口返回
- 数据持久化
- 所属租户
- 业务状态
- 操作日志
